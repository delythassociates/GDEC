# GDEC Work Package 2 (WP2) Risk Register

| Risk ID | Description | Severity | Likelihood | Impact on GDEC | Mitigation Strategy | Status |
|---|---|---|---|---|---|---|
| `RISK-WP2-01` | Upstream scientific dependency drift (NumPy 2.x, SciPy 1.14+, scikit-fem 10.x) deprecations break FEM kernels | Medium | High | Silent numerical corruption or test failures during unpinned CI builds | Dedicated `upstream-dependency-drift` CI job runs weekly cron + PR against latest dependencies; version bounds pinned in `pyproject.toml`. | **MITIGATED** |
| `RISK-WP2-02` | Unverified capability claims drift between `docs/` and actual codebase test coverage | High | Medium | Engineering decisions made on unverified or regressed numerical routines | Machine-readable `results/status_register.json` generated and verified via `scripts/generate_status_register.py --check` in CI gate. | **MITIGATED** |
| `RISK-WP2-03` | False sense of security from superficial unit test coverage without testing physics | High | Medium | Tests pass trivial assertions while physical simulation produces incorrect stiffness or stress | Targeted mutation testing harness (`mutation_harness.py`) tests lethal mathematical mutations; 100% kill rate verified in CI. | **MITIGATED** |
| `RISK-WP2-04` | Naive convergence order assertions failing due to legitimate physical singularities (e.g., L-shaped re-entrant corner) | Medium | High | Flaky CI builds or incorrectly loosening tolerances | Convergence tests explicitly distinguish smooth $C^\infty$ problems ($p \approx 2$) from fractional Sobolev singularities $H^{1+\alpha}$ ($p \approx 1.33$ in $L^2$). | **MITIGATED** |
| `RISK-WP2-05` | Untracked user files (`analyser.py`, `src/gdec/runtime/`) accidentally committed or overwritten during branch cut/merge | Critical | Low | Loss of proprietary user-developed runtime analysis code | Strict non-negotiable repository safeguard enforced in git add/commit process and CI preflight. | **ACTIVE MONITORING** |
